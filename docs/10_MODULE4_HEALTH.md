# 10 — Module 4: Crop health (/health)

Fully interactive demo.
- Upload or take a leaf photo, preview, "Analyze" with a scanning animation.
- Result card: possible issue (from a small mock set of common Maharashtra crop issues), severity (Low/Moderate/High), suggested next steps, "Consult your local KVK / agriculture officer" button.
- Prominent banner: "Demo AI suggestion, not a diagnosis. Not a validated model."
- Do not show accuracy percentages or exact treatment doses.
- If a Gemini key is available, may send the image for a structured JSON suggestion, validate it, and apply the same banner; otherwise use the mock set.
