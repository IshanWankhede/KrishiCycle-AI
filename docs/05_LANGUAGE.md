# 05 — Language

English, Hindi (hi), Marathi (mr).

- One typed central translation dictionary. Missing keys fall back to English without crashing.
- Translate navigation, form labels, buttons, statuses, validation messages, empty states and core flows.
- After the farmer picks a district during sign-up, show a friendly modal: "We suggest Marathi for Pune. Continue in English or switch to Marathi?" with a one-tap choice. Location is only a hint; the user chooses.
- Language switcher always visible in the nav and in the profile.
- Quantities, units and safety warnings are structured data, formatted per language, never free-translated.
